Frequently Asked Questions

Does reversing lose audio quality?

No. Only the sample order is flipped, so the result plays backwards at the exact same quality as the original with no compression or loss.

What output format do I get?

A WAV file (16-bit PCM). Use the format converter if you need a different format.

Is my file uploaded to a server?

No. All processing happens locally in your browser and nothing is sent to a server.
